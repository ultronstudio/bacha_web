# Detection Engine v2 backend

AI schema includes scam type, requested actions, evidence families and incomplete verification. The existing validated result and quota pipeline remain backward compatible. Correlated model signals use the strongest weight per family. Model self-confidence does not multiply severity. Unchecked external providers cannot mark a URL malicious. Existing Google Web Risk, PhishTank and URLhaus adapters remain opt-in via server configuration. No feed key, live provider, direct URL crawl or RDAP service is enabled by this commit. Before activation verify current provider licensing, privacy and quotas. Arbitrary redirect traversal requires a dedicated isolated network worker, DNS pinning and public IP checks on every hop; never add unrestricted fetch to this API. Evaluate independent holdout and actual device/cloud before release.
